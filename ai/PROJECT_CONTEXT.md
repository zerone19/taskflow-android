# Agent Project Context

## Project

TaskFlow Android Agent Sandbox.

## Purpose

This is a controlled test project used to evaluate an AI agent before allowing it to work on a larger Android application.

## Current Phase

Project initialization and agent evaluation.

## Technology Direction

Kotlin + Jetpack Compose + Material 3.

Additional libraries should only be introduced when justified by a requirement or test.

## Design

Design references live under:

`design/`

Documentation lives under:

`docs/`

## Important Principle

The sandbox is intentionally small. Do not add production-scale complexity without a specific evaluation reason.

## Success Criteria

The agent should demonstrate disciplined engineering behavior:

Understand → Inspect → Plan → Implement → Build → Test → Verify → Report.
