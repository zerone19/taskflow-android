# Agent Task Workflow

## Phase 1 — Understand

Read the relevant requirement and identify the exact requested outcome.

## Phase 2 — Inspect

Inspect existing files, architecture, dependencies, and design references.

## Phase 3 — Plan

Describe the smallest reasonable implementation plan.

## Phase 4 — Implement

Make focused changes.

## Phase 5 — Build

Run the relevant Gradle build task.

## Phase 6 — Test

Run relevant unit/UI/integration tests.

## Phase 7 — Run

When applicable, install and run on an emulator or physical Android device.

## Phase 8 — Verify

Check actual output, logs, and behavior.

## Phase 9 — Report

Report actual changes and actual verification results.

## Stop Conditions

Stop and ask when:

- a destructive operation needs authorization;
- a major design decision is ambiguous;
- an API contract is missing for required networking;
- a required external dependency cannot be verified;
- the requested change conflicts with project rules.
