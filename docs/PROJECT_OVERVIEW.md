# Project Overview

## Project Name

TaskFlow

## Project Type

Android native application untuk pengujian AI agent.

## Purpose

TaskFlow digunakan sebagai proyek kecil untuk menguji workflow engineering AI agent sebelum agent digunakan pada proyek Android yang lebih besar.

## Target Platform

- Android phone
- Android tablet sebagai pertimbangan adaptive UI

## Technology Direction

- Kotlin
- Jetpack Compose
- Material 3
- Android Jetpack
- ViewModel
- Coroutines / Flow
- Navigation
- Room jika dibutuhkan pada tahap persistence
- Android testing tools
- Gradle

## Core Objective

Membangun task manager sederhana sambil mengevaluasi kemampuan agent dalam:

1. Project inspection
2. Design analysis
3. Architecture planning
4. UI implementation
5. Local data handling
6. Navigation
7. Testing
8. Debugging
9. Build and verification
10. Agent discipline

## Non-Goals

Project ini tidak bertujuan menjadi aplikasi task manager production-ready.

Jangan menambahkan fitur besar yang tidak diperlukan untuk pengujian.
