# Data Model

## Task

Conceptual model:

- id
- title
- description
- priority
- completed
- createdAt
- updatedAt

## Priority

Priority dapat direpresentasikan sebagai nilai yang jelas dan type-safe.

Contoh konsep:

- LOW
- MEDIUM
- HIGH

## Persistence

Persistence lokal dapat menggunakan Room jika tahap pengujian memerlukannya.

Jangan menambahkan database hanya untuk memperbesar project.
